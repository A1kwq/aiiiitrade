# 📊 Crypto AI Trader

Торговый журнал с **обучаемым ИИ-ботом** в стиле [StatsAI](https://statsai.xyz/#day).

## Возможности

| Фича | Описание |
|------|----------|
| **Дашборд** | KPI: win rate, P&L (R), max drawdown, avg R. График накопительного P&L |
| **Журнал сделок** | Запись: символ, направление, TF, сессия, сетап, bias, entry/exit, SL, R |
| **ИИ-бот** | Обучаемая модель (Gradient Boosting). Предсказывает вероятность успеха сетапа |
| **Аналитика по сессиям** | Win rate в Азии / Европе / US |
| **Аналитика по сетапам** | Win rate по FVG, OB, VWAP, EMA/RSI, ATR |
| **Важность фичей** | Что реально влияет на результат (не только TF) |

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить
streamlit run app.py
```

Откроется `http://localhost:8501`

## Структура проекта

```
crypto_ai_trader/
├── app.py              # Streamlit UI (StatsAI-дизайн)
├── ai_bot.py           # Обучаемый ИИ-бот (GradientBoosting)
├── database.py         # SQLite хранилище сделок
├── config.py           # Настройки: TF, сессии, сетапы
└── requirements.txt
```

## Как работает ИИ-бот

1. **Собираешь сделки** — заполняешь журнал (минимум 10)
2. **Обучаешь модель** — нажимаешь "🎓 Обучить"
3. **Оцениваешь новые сетапы** — бот даёт вероятность успеха %
4. **Видишь что важно** — importance фичей показывает, какой TF/сессия реально влияет

## Настройка под себя

Отредактируй `config.py`:
- Добавй свои символы
- Поменяй сетапы (FVG → BOS, OB → Order Block и т.д.)
- Твоя сессия по умолчанию
